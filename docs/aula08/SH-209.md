# SH-209 — Refresh Preview for Saved Content

## Status

Ready for Refinement

## User Story

As a user, I want to refresh the preview of saved content so I can update outdated preview information without recreating the content item.

## Proposed Behaviour

A saved content item should provide an action that allows the user to refresh its preview information using the content URL.

## Relevant Existing Requirements

- FR-28 — Fetch Open Graph metadata from a URL.
- FR-30 — Refresh Preview for saved content.

## Open for Refinement

The detailed behaviour still needs to be clarified before implementation.

Questions may include:

- what exactly is refreshed;
- which saved content can use the action;
- what happens when the content has no URL;
- what happens when metadata cannot be fetched;
- whether existing title or description can be changed;
- what feedback the user receives;
- whether ownership or other existing restrictions apply.

Do not assume answers that are not supported by the PRD or refinement decisions.
