# Changelog

## [1.0.0] - 2026-03-27

### Added
- User authentication with email-based login and registration
- Content management: create, read, update, delete with file upload support
- Open Graph preview image fetching for URL-based content
- Categories and Tags for organizing content (user-scoped)
- Dashboard with aggregated statistics and activity charts
- AI-powered insights using Anthropic Claude API (summaries, key points, study questions, flashcards)
- Full-text search and filtering on content list
- Pagination on content list
- Docker deployment setup with Gunicorn and Whitenoise
