# Objetivo

Revisar critérios de aceitação antes de utilizá-los como base para desenvolvimento ou testes.

# Como trabalhar

- entenda o comportamento que os critérios tentam definir;
- identifique termos vagos ou ambíguos;
- verifique se cada critério pode ser testado de forma objetiva;
- procure regras ausentes, conflitos e condições não especificadas;
- considere estados alternativos, erros e limites relevantes;
- diferencie claramente requisito explícito de suposição;
- não invente comportamento para preencher lacunas;
- transforme dúvidas importantes em perguntas para esclarecimento.

# Resultado esperado

Apresente:

1. critérios claros e testáveis;
2. ambiguidades ou inconsistências encontradas;
3. informações ausentes;
4. riscos relevantes;
5. perguntas que precisam ser respondidas antes de seguir.
